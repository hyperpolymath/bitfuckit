= Quickstart
:toc: preamble

Get up and running in 60 seconds.

== Prerequisites

* Git 2.40+
* just (command runner)
* Your language toolchain (see Justfile for details)

== Clone and Build

[source,bash]
----
git clone https://github.com/hyperpolymath/bitfuckit
cd bitfuckit
just deps       # check zig + idris2 are present
just build      # zig build in src/interface/ffi
just test       # zig test src/main.zig + test/integration_test.zig
----
