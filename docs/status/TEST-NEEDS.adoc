== Removed template machinery

Three files that tested the *template's own* instantiation mechanism (not
anything about bitfuckit) were deleted rather than instantiated, since
"instantiating" a test of the placeholder-substitution process makes no sense
once the substitution has actually happened:

* `scripts/validate-template.sh` — 8-phase RSR template structure validator
* `tests/e2e/template_instantiation_test.sh` — cloned the template, substituted
  placeholders with test values, and validated the result
* `benches/template_bench.sh` — benchmarked the above two scripts

Nothing in `.github/workflows/`, the root `Justfile`, or `build/just/*.just`
invoked these three files directly (verified by grep before deletion), so no
CI surgery was needed.
